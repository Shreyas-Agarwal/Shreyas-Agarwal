## 🚀 About Me

I’m fundamentally a data person.

Most of the systems I work on — backend platforms, workflow engines, automation pipelines — make sense to me because I understand the information moving through them.

Data shapes system behavior:
- structure,
- coordination,
- operational constraints,
- and eventually, failure modes.

That’s usually where my curiosity starts.

A lot of my work revolves around identifying where systems fracture under scale, coordination, or operational complexity — and redesigning the flow before the friction becomes normalized.

Currently exploring:
- ⚙️ workflow automation
- 🏗️ BIM & construction tech
- 🧠 distributed systems
- 📊 data-intensive applications
- 🛠️ developer tooling
- 🤖 AI-assisted workflows
